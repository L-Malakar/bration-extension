Features

Blocking happens at every layer

Not just the requests you can see — the ones that render as page content too.

NETWORK

Network-level blocking

A stacked filter list — EasyList, EasyPrivacy, AdGuard Base, AdGuard Annoyances, plus dedicated scam and malvertising-redirect lists — checked against every request by a Rust engine compiled to WebAssembly.

COSMETIC

Cosmetic filtering

Hides ad containers and sponsored banners that load as page content, not just requests a network filter could catch.

POPUP

Popup blocking

Automatically closes ad-triggered popup tabs before they get in your way.

REDIRECT

Forced-redirect protection

Stops cross-site scripts from hijacking your navigation and dropping you on scam pages.

PER-SITE

Per-site control

Turn blocking off for one specific site without affecting any other tab or domain.

DASHBOARD

Dashboard

A WhatsApp-style view of every domain you've visited over the last 30 days, with a full breakdown of exactly what got blocked and where.

How it works

One Rust core, three jobs

The engine compiles once to WebAssembly, then splits into three separate defenses inside the browser.

adblock-rust (Rust)
──▶ compiled to WebAssembly ──▶
bration_extinction_core_bg.wasm
├── Network blocking
→ webRequest interception
├── Cosmetic filtering
→ CSS injection via content script
└── Popup / redirect guard
→ webNavigation heuristics
Privacy

Nothing leaves your machine

The extension's manifest explicitly declares zero data collection — this isn't a policy promise, it's a technical one.

  • Everything is stored locally, in your browser's own storage
  • No account, sign-in, or sync required to use any feature
  • No external server ever receives your browsing data

Read the full policy for the exact detail on what is (and isn't) collected.
